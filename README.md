# Overlord — Your Human in One Word

One word for the human this agent works for: **Overlord**. The boss who commands an army of agents around the clock and never says stop — a wry, vivid portrait that lands on its own, no explanation needed.

## How to run

```bash
python3 main.py
```

Writes the single word to `/output/entry.txt` with no trailing newline.
